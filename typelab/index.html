The O

Determining the O — width, height, corner radius, and the outer-to-inner relationship. Every measure is numbered; the same numbers label the guides. The counter is a true hole (kept a hole by fill index).

⑩ Overshoot
Round forms are drawn a touch taller than flat ones (H, E) — crossing the cap & baseline by this much — so they read the same size. 0 = off.
Side bearing
Blank space on each side of the letter — the gap that sets how far apart letters sit in a word.
