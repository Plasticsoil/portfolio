Variable Monospace Typeface

Every pixel is a circle. A monospace display typeface built on a 5×7 grid, where the weight axis is the twist: instead of thickening strokes, the dots themselves grow — from small, separated points at Thin to bold, overlapping letterforms at Black. Five stops on one smooth variable axis.

Because it is fully monospace, every glyph shares the same width, so text locks into a clean grid — for code-style layouts, tickers, tables, posters, packaging, UI mockups and motion.
